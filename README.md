# RShell

用 Rust 实现的 FinalShell 风格 SSH 终端:左侧系统监控、中间终端、下方 SFTP 文件管理器、顶部多会话标签页。

低内存占用:实测多标签页前台运行内存低于 300MB,后台约 150MB。

## 功能

- **SSH 会话**:密码 / 私钥认证,多标签页,断线提示;已保存连接支持文件夹分组
- **SSH 密钥管理**:生成 Ed25519 / RSA 密钥对、登记已有私钥、删除;生成的私钥以 0600 权限存入配置目录,密钥口令由系统钥匙串保管
- **连接导入 / 导出**:JSON 格式,可选明文或密码加密(AES-256-GCM);支持导出全部、单个连接或整个文件夹(含子文件夹),导入时按主机与用户名去重合并并保留分组
- **主机指纹校验(TOFU)**:首次连接弹窗确认 SHA256 指纹,指纹变更时强警告(`known_hosts.toml`)
- **密码存储**:默认使用 macOS 钥匙串或 Windows 凭据管理器；可显式切换为 App 内 AES-256-GCM 兼容存储（密钥与密文同目录），切换时会迁移已知凭据
- **终端**:基于 alacritty_terminal 的终端模拟(ANSI/256 色/滚回/选区复制/括号粘贴/IME 中文输入);可配置右键粘贴
- **本机终端**:在新建连接标签页中直接打开本地 shell(portable-pty,跨平台)
- **系统监控侧栏**:运行时间/负载/CPU/内存/交换、进程 Top10、网络速率双折线图、延迟、磁盘用量(远程 Linux 主机经 SSH exec 采集 `/proc`,本机经后台 sysinfo 线程每秒采样)
- **文件管理器**:SFTP/本机统一浏览,目录树懒加载、排序、重命名/删除/新建、上传下载带进度、拖拽文件到面板直接上传
- **命令输入条**:回车发送到当前终端,↑↓ 翻阅历史,常用命令一键执行
- **界面个性化**:主题模式(跟随系统/深色/浅色)、四种配色(蓝/绿/紫/橙)、终端等宽字体与字号、终端背景(纯色或图片,支持填充/适应/拉伸/居中/平铺及遮罩强度)
- **独立工具窗口**:设置、连接库和内建编辑器使用独立原生窗口，可拖出主窗体或移动到其他显示器;macOS 下 Dock 右键可列出并切换窗口
- **内建编辑器**:独立原生窗口,多文件标签页,行号 + 语法高亮(syntect,明暗主题自动跟随,可分别自定义深色/浅色高亮主题或加载 .tmTheme),自动折行、重开窗口恢复上次文件,搜索/替换(⌘F / Ctrl+F)、摘要冲突检测、保留文件权限的原子保存;编辑 `/etc` 等受保护文件时可显式使用安全的 sudo 管理员保存,未保存关闭有确认(详见 [管理员保存](docs/PRIVILEGED_SAVES.md))
- **在线预览文件**:文件管理器双击文本文件直接查看/编辑;按执行位和扩展名判断类型,类型不明确时读取远程文件前 8KB 进行内容嗅探,必要时调用远程 `file` 命令;非文本文件弹窗提示,10MB 以上先确认,16MB 以上仅支持外部程序/下载,512KB 以上自动关闭语法高亮以保证流畅
- **传输设置**:下载路径可选每次询问保存位置或下载到指定目录;文件打开方式可配置为调用本地程序打开(保存后自动上传回远程),均在设置 → 传输设置中配置

## 构建运行

```bash
cargo run --release
cargo test          # 单元与回环测试：pty、SSH、监控解析、文件服务、known_hosts、存储工具
cargo test keyring_roundtrip -- --ignored   # 单独运行真实系统 keyring 读写测试
```

## 软件更新与发布

应用使用平台对应的安全更新机制：macOS 使用内嵌的 Sparkle 2，Windows 使用签名 MSIX + 系统 App Installer。发布完全在 GitHub 进行，无需 Apple Developer 账号：Actions 工作流构建、自签名并自动发布到 Releases，更新清单（appcast.xml / .appinstaller）也由 Releases 托管。

首次安装时 macOS 需右键 → 打开（未公证），Windows 需先信任发布用的自签名证书；之后的版本更新自动完成。开发构建默认不连接更新服务器；签名、清单生成和发布步骤见 [docs/UPDATES.md](docs/UPDATES.md)。

## 技术栈

eframe / egui 0.35 · alacritty_terminal · russh + russh-sftp · portable-pty · sysinfo · keyring · tokio · syntect
