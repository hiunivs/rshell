# Lucide icons

Selected SVG icons from Lucide v0.468.0:
https://github.com/lucide-icons/lucide/tree/0.468.0/icons

Only icons used by RShell are bundled. Lucide is licensed under the ISC
license; see `LICENSE` in this directory.

The bundled copies use white strokes instead of `currentColor`. This preserves
the Lucide geometry while allowing egui's multiplicative image tint to apply
the active light/dark theme color correctly.
