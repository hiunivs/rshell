# Contributing to RShell

Thank you for considering a contribution. RShell uses an AGPL/commercial dual-licensing model, so the project must have sufficient rights to offer accepted contributions under both alternatives.

Before a contribution can be merged, every copyright holder of that contribution must sign the current RShell Contributor License Agreement supplied by hiunivs. The agreement must permit hiunivs to use, modify, distribute, sublicense, and relicense the contribution, including under commercial terms. A pull request, issue comment, or Developer Certificate of Origin sign-off by itself does not grant those additional relicensing rights.

Contact **ai-cube@outlook.com** before submitting a substantial contribution to obtain and sign the current agreement. Do not submit code that you do not have authority to license, including employer-owned code or third-party code whose terms are incompatible with RShell.

Accepted contributions remain attributable to their authors. The contributor agreement does not transfer ownership unless its separately signed terms explicitly say otherwise.
